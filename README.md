# 📘 Guía de Servicios en Sistemas Linux y Windows
Este repositorio contiene explicaciones detalladas y prácticas sobre cómo configurar y administrar servicios esenciales en sistemas operativos Linux y Windows. Está pensado como recurso educativo para estudiantes, técnicos y entusiastas de la administración de sistemas.
# 🧰 Servicios Cubiertos
- DHCP (Dynamic Host Configuration Protocol)
- DNS (Domain Name System)
- FTP (File Transfer Protocol)
- HTTP/HTTPS (Servidores web con Apache/Nginx/IIS)
- SSH (Secure Shell)
- SMTP/POP3/IMAP (Servicios de correo electrónico)
- Firewall y NAT
- Compartición de archivos (Samba, NFS, etc.)
# 📂 Estructura del Repositorio
Cada carpeta contiene:
- Explicación paso a paso
- Capturas de pantalla (si aplica)
- Archivos de configuración de ejemplo
- Pruebas básicas para verificar el servicio
# 🚀 Objetivo
El objetivo de este repositorio es facilitar el aprendizaje práctico de la administración de servicios en entornos reales, tanto en servidores como en máquinas virtuales o laboratorios de estudio.
# 🛠️ Requisitos
- Conocimientos básicos de redes
- Familiaridad con la línea de comandos (CMD, PowerShell, Bash)
- Entornos de prueba como máquinas virtuales (VirtualBox, VMware, etc.)
# 📚 Recursos Adicionales
Se incluirán enlaces a documentación oficial, tutoriales en video y libros recomendados para profundizar en cada servicio.
